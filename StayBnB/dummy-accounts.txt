Notes
-----
- New registrations always receive the Guest role.
- Approving a host application adds the Host role and removes the Guest role.
- Only a SuperAdmin can promote a Guest to Admin.
- The SuperAdmin password is read from the "SuperAdmin:Password" configuration value.
- Demo passwords can be overridden with configuration such as "DemoUsers:Host:Password".
- Change or remove these credentials before any public deployment.
